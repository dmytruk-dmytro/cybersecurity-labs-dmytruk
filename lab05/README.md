# Email-Шифратор

## Опис проекту
Програма призначена для демонстрації принципів симетричного шифрування електронних повідомлень. Ключ генерується на основі персональних даних користувача, що забезпечує прив'язку шифрування до конкретної особи.

Система розроблена для навчальних цілей (лабораторна робота), щоб продемонструвати роботу з криптографічними бібліотеками Python.

## Функціональні можливості
1.  **Персоналізація ключів:** Генерація унікального ключа шифрування на основі введених персональних даних.
2.  **Захист даних:** Симетричне шифрування тексту електронного листа.
3.  **Перевірка дешифрування:** Інтерактивна можливість перевірити коректність відновлення початкового тексту.

## Технічні вимоги
* Python 3.x
* Бібліотека: `cryptography`

## Як запустити
1.  **Встановіть залежності.**
    Відкрийте термінал та виконайте команду для встановлення модуля шифрування:
    ```bash
    pip install cryptography
    ```

2.  **Збережіть код програми** у файл `main.py`.

3.  **Запустіть програму:**
    ```bash
    python main.py
    ```

## Інструкція з використання

### Крок 1: Генерація ключа
Після запуску програма попросить ввести:
* Персональні дані.
* Вашу електронну пошту.
*На основі цих даних буде створено ваш ключ шифрування.*

### Крок 2: Шифрування повідомлення
1.  Напишіть текст повідомлення, яке ви хочете захистити.
2.  Програма автоматично зашифрує його.

### Крок 3: Перевірка
1.  Для перевірки роботи алгоритму (розшифрування) введіть **'так'** у відповідь на запит програми.
2.  Повторно вкажіть ключ, щоб побачити розшифрований текст.
