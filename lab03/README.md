# LSB Steganography Tool

## Опис проекту
Цей інструмент реалізує метод стеганографії LSB (Least Significant Bit) для приховування текстових повідомлень всередині зображень. Скрипт працює на низькому рівні з пікселями, змінюючи останній біт у кожному колірному каналі (RGB) на біт секретного повідомлення.

Це дозволяє передавати приховану інформацію, візуально не змінюючи вигляд оригінального зображення.

## Функціональні можливості
* **Інтерактивність:** Введення секретного повідомлення безпосередньо через консоль.
* **Підтримка UTF-8:** Повна підтримка української мови, спецсимволів та емодзі.
* **Цілісність даних:** Використання формату **PNG** для збереження результату, що запобігає втраті даних через компресію (на відміну від JPEG).
* **Надійність зчитування:** Використання спеціального стоп-маркера (`#####`) для точного визначення кінця повідомлення при дешифруванні.

## Технічні вимоги
* Python 3.x
* Бібліотека: `Pillow` (для обробки зображень)

## Як запустити

1.  **Встановіть залежності.**
    Виконайте команду в терміналі для встановлення бібліотеки обробки зображень:
    ```bash
    pip install pillow
    ```

2.  **Підготуйте файли.**
    * Збережіть код програми у файл `main.py`.
    * Помістіть у ту ж папку будь-яке зображення та перейменуйте його на **`input.jpg`**.

3.  **Запустіть програму:**
    ```bash
    python main.py
    ```

## Інструкція з використання

### Крок 1: Введення даних
Після запуску скрипт запросить введення:
`>> Введіть секретне повідомлення:`
Напишіть будь-який текст (латиницею або кирилицею) і натисніть **Enter**.

### Крок 2: Генерація стего-зображення
Програма обробить `input.jpg` та створить новий файл **`output_stego.png`**. Саме цей файл містить ваше приховане повідомлення.

### Крок 3: Автоматична перевірка
Скрипт одразу спробує зчитати дані з новоствореного файлу `output_stego.png` та виведе розшифрований текст у консоль для підтвердження успішної роботи.

## Принцип роботи алгоритму
1.  **Конвертація:** Текст повідомлення перетворюється на байти (UTF-8), а потім на послідовність бітів (0 та 1).
2.  **Вбудовування:** Програма проходить по матриці пікселів зображення. У кожному каналі (Red, Green, Blue) останній біт замінюється на біт повідомлення.
    * *Приклад:* `11010100` (оригінальний колір) -> `11010101` (з повідомленням).
3.  **Результат:** Зміна кольору на 1 одиницю є абсолютно непомітною для людського ока, але дозволяє комп'ютеру зчитати приховану інформацію.
