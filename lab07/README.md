# SecureHide Analytics

## Опис проекту
**SecureHide Analytics** — це комплексна система захисту інформації, призначена для автоматизованого шифрування файлів та їх прихованого вбудовування у графічні об'єкти (стеганографія).

Програма не лише захищає дані, а й надає аналітичний звіт щодо ефективності алгоритмів, вимірюючи час обробки та зміни розмірів файлів на кожному етапі трансформації даних.

## Функціональні можливості
1.  **Комплексний захист:** Поєднання симетричного шифрування даних із методами стеганографії.
2.  **Автоматизація процесів:** Автоматична генерація секретних даних (якщо вони відсутні) та їх обробка.
3.  **Приховування даних:** Створення зображення-контейнера, що візуально не відрізняється від оригіналу, але містить зашифрований файл.
4.  **Аналітика:** Виведення у консоль детального звіту з таймінгами операцій та метриками файлів (вхідний розмір vs вихідний розмір).

## Технічні вимоги
* Python 3.8 або вище.
* Зовнішні бібліотеки: `Pillow` (обробка зображень), `cryptography` (шифрування).

## Як запустити
1.  **Встановіть залежності.**
    Відкрийте термінал та виконайте команду:
    ```bash
    pip install Pillow cryptography
    ```

2.  **Підготуйте файли.**
    * Покладіть файл скрипта `main.py` у робочу папку.
    * У цю ж папку помістіть зображення-контейнер з назвою `input_cover.jpg`.

3.  **Запустіть програму:**
    ```bash
    python main.py
    ```

## Результати роботи та файли

Після виконання скрипта у вашій директорії з'являться наступні файли:

* **`encoded_output.png`** — зображення з прихованими всередині зашифрованими даними.
* **`restored_data.txt`** — файл, що містить інформацію, успішно відновлену після циклу дешифрування.
* *(Опціонально)* Текстовий файл із секретом (якщо він не був створений вручну заздалегідь).

### Аналітичний звіт
У консолі буде відображено статистику:
* Час, витрачений на шифрування та приховування.
* Час, витрачений на вилучення та дешифрування.
* Порівняння розмірів оригінальних та оброблених файлів.
