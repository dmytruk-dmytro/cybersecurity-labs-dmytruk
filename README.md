# cybersecurity-labs-dmytruk

## Опис репозиторію
Цей репозиторій є повним зібранням виконаних лабораторних робіт з навчальної дисципліни **«Безпека програм та даних»**. Проєкт об'єднує програмні рішення для захисту інформації, криптографічні інструменти та звіти з аудиту безпеки.

Тут представлені як вихідні коди програм (Python), так і супровідні матеріали: інструкції з використання, скріншоти роботи програм та файли залежностей.

**Інформація про виконавця:**
* **Студент:** Дмитрук Д. А.
* **Група:** 6.04.121.013.22.2
* **Університет:** ХНЕУ ім. С. Кузнеця

## Структура курсу
Репозиторій організовано за тематичними модулями. Кожна папка відповідає окремій лабораторній роботі:

1.  **Lab 01: Аудит власної цифрової безпеки**
    Аналіз вразливостей, перевірка паролів та налаштувань безпеки облікових записів.
2.  **Lab 02: Захист особистих повідомлень**
    Реалізація алгоритмів шифрування для конфіденційного листування.
3.  **Lab 03: Невидимі дані у власних файлах**
    Використання стеганографії для приховування інформації в медіафайлах.
4.  **Lab 04: Особистий цифровий підпис**
    Створення системи підпису файлів для гарантії їх цілісності та авторства.
5.  **Lab 05: Захищена електронна пошта**
    Комплексна робота з протоколами захисту email-повідомлень.
6.  **Lab 06: Етичний хакінг власного застосунку**
    Тестування програмного забезпечення на вразливості (SQL Injection, XSS тощо).
7.  **Lab 07: Комплексний захист особистого проєкту**
    Підсумкова робота, що поєднує різні методи захисту даних.

## Технічні вимоги
Для коректної роботи всіх лабораторних робіт необхідне наступне середовище:

* **Мова:** Python 3.x
* **Система контролю версій:** Git
* **Ключові бібліотеки:** `cryptography`, `Pillow`, `sqlite3` та інші (зазначені в `requirements.txt` відповідних папок).

## Як розгорнути та запустити

1.  **Клонування репозиторію.**
    Для отримання локальної копії всіх матеріалів виконайте команду:
    ```bash
    git clone [https://github.com/dmytruk-dmytro/cybersecurity-labs-dmytruk.git](https://github.com/dmytruk-dmytro/cybersecurity-labs-dmytruk.git)
    ```

2.  **Перехід до лабораторної роботи.**
    Кожна робота є автономним проєктом. Перейдіть у відповідну папку:
    ```bash
    cd lab01  # Або lab02, lab03 і т.д.
    ```

3.  **Запуск.**
    Детальні інструкції щодо запуску конкретної програми знаходяться у файлі `README.md` всередині кожної папки. Зазвичай запуск виконується командою:
    ```bash
    python main.py
    ```

## Додаткові матеріали
У кожній папці ви знайдете:
* `main.py` — основний код програми.
* `README.md` — детальна документація до конкретної роботи.
* `Скріншоти` з доказами працездатності коду.
* `Додаткові файли` для окремих робіт з вхідними та вихідними даними.
