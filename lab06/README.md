# SQL Injection Demo & Defense

## Опис проекту
Цей застосунок створений для демонстрації уразливості типу SQL-ін'єкція (SQL Injection) та методів захисту від неї. Програма імітує роботу корпоративної системи пошуку співробітників за іменем або прізвищем, дозволяючи наочно порівняти безпечний та небезпечний підходи до обробки запитів.

## Функціональні можливості
1.  **Імітація корпоративної БД:** Робота з локальною базою даних співробітників.
2.  **Вразливий режим:** Демонстрація виконання запитів без санітизації даних, що призводить до витоку інформації.
3.  **Захищений режим:** Реалізація параметризованих запитів, що унеможливлює ін'єкцію.
4.  **Етичний хакінг:** Можливість протестувати систему на злом за допомогою спеціальних SQL-конструкцій.

## Технічні вимоги
* Python 3.x
* Стандартна бібліотека: `sqlite3` (входить у стандартний пакет Python, додаткове встановлення не потрібне).

## Як запустити
1.  Збережіть код програми у файл `main.py`.
2.  Відкрийте термінал або командний рядок.
3.  Запустіть програму командою:
    ```bash
    python main.py
    ```

## Інструкція з використання

### Крок 1: Нормальний пошук
Використовуйте програму як звичайний користувач для пошуку колег.
* **Введення:** Введіть ім'я, наприклад `Артем` або `Бондаренко`.
* **Результат:** Система знайде конкретного співробітника та виведе інформацію про нього.

### Крок 2: Атака (SQL-ін'єкція)
Спробуйте отримати доступ до прихованих даних, використовуючи вразливість коду.
* **Введення:** Введіть шкідливий код:
    ```sql
    ' OR 1=1--
    ```
* **Результат (Вразлива версія):** Виведе повний список усіх співробітників бази даних, включаючи їхні секретні паролі, оскільки умова `1=1` завжди істинна.
* **Результат (Захищена версія):** Повідомить, що нічого не знайдено. Система сприйме введений код як буквальний рядок тексту, а не як команду SQL.
